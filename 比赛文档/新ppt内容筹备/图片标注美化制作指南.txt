【详细制作步骤】
====================================================================

■ 第一步：插入圆角矩形形状（预计耗时：30秒）

【操作1：打开形状菜单】
→ 用鼠标点击PPT顶部菜单栏的"插入"选项卡
→ 在"插入"选项卡中，找到"形状"按钮（通常在"插图"组里）
→ 点击"形状"按钮，会弹出一个形状列表

【操作2：选择圆角矩形】
→ 在形状列表中，找到"矩形"分类
→ 选择"矩形：圆角"（注意：不是普通的"矩形"，是带圆角的）
→ 鼠标指针会变成十字形

【操作3：绘制矩形】
→ 在第一张手机截图的正上方位置
→ 按住鼠标左键不放，向右下方拖动
→ 拖出一个矩形（先不用管大小，后面会精确调整）
→ 松开鼠标

【操作4：精确调整大小】
→ 确保矩形仍然被选中（四周有圆圈标记）
→ 看PPT顶部工具栏，找到"形状格式"选项卡
→ 在"形状格式"选项卡的右侧，找到"大小"组
→ 看到"高度"和"宽度"两个输入框
→ 点击"宽度"输入框，输入：4.5厘米（或180像素）
→ 点击"高度"输入框，输入：1.2厘米（或45像素）
→ 按回车键确认

✅ 完成！此时你应该得到一个大小合适的圆角矩形。


■ 第二步：设置矩形的颜色和阴影（预计耗时：2分钟）

【操作1：打开"设置形状格式"面板】
→ 确保矩形仍然被选中
→ 用鼠标右键点击矩形
→ 在弹出的菜单中，找到并点击"设置形状格式"
→ 此时PPT右侧会出现一个"设置形状格式"面板（如果没出现，检查是否点对了）

【操作2：设置填充颜色 - 深蓝色】
→ 在右侧面板中，确保选中"填充"图标（油漆桶图标）
→ 点击"填充"，展开选项
→ 选择"纯色填充"（点击前面的圆点）
→ 点击"颜色"下拉按钮，会出现颜色选择器
→ 点击颜色选择器下方的"其他颜色"
→ 在弹出的窗口中，选择"自定义"选项卡
→ 看到RGB输入框，分别输入：
   * R（红）：30
   * G（绿）：58
   * B（蓝）：138
→ 点击"确定"
→ 确保"透明度"滑块在最左边（0%）

✅ 此时矩形应该变成了深蓝色。

【操作3：去掉边框】
→ 在右侧面板中，点击"线条"图标（旁边的图标）
→ 展开"线条"选项
→ 选择"无线条"（点击前面的圆点）

✅ 此时矩形边框消失了。

【操作4：添加阴影效果】
→ 在右侧面板中，点击"效果"图标（五角星图标）
→ 展开"阴影"选项
→ 点击"预设"按钮
→ 在弹出的阴影样式中，选择"外部" → "偏移：右下"
   （如果找不到，选择任意外部阴影即可）

【操作5：微调阴影参数（重要！让阴影更自然）】
→ 在"阴影"选项下方，展开详细参数
→ 找到并设置以下参数：
   * 颜色：点击颜色按钮 → 选择"黑色"
   * 透明度：拖动滑块到 50% 左右（让阴影不要太重）
   * 大小：保持 100%
   * 模糊：拖动滑块到 8 磅左右（数字越大越柔和）
   * 距离：拖动滑块到 4 磅左右
   * 角度：输入 315 度（右下方向）

✅ 完成！此时矩形应该有了自然的阴影效果。


■ 第三步：在矩形内添加白色文字（预计耗时：1分钟）

【操作1：输入文字】
→ 用鼠标左键双击矩形内部
→ 此时会出现一个闪烁的光标，表示可以输入文字了
→ 直接用键盘输入："步骤1：智能感知"
→ 输入完成后，用鼠标拖动选中所有文字（按住左键拖动，或按Ctrl+A全选）

【操作2：设置文字格式】
→ 确保文字仍然被选中（文字背景是蓝色或灰色）
→ 看PPT顶部工具栏，找到"开始"选项卡
→ 在"字体"组中进行以下设置：

   ▶ 设置字体：
   → 点击字体下拉框（默认可能是"宋体"或"Calibri"）
   → 找到并选择"微软雅黑"
   
   ▶ 设置字号：
   → 点击字号下拉框（默认可能是"18"或其他）
   → 选择"16"或"14"（建议先用16试试，太小再调）
   
   ▶ 设置加粗：
   → 点击"加粗"按钮（图标是"B"，或按快捷键Ctrl+B）
   → 文字会变粗
   
   ▶ 设置颜色为白色：
   → 点击"字体颜色"按钮（图标是"A"下面有一条横线）
   → 点击下拉箭头
   → 在颜色选择器中选择"白色"（第一排第一个，或最后一个）

【操作3：设置文字对齐方式】
→ 点击矩形外部，取消文字选中状态
→ 再次点击矩形，选中整个矩形（不是文字）
→ 用鼠标右键点击矩形
→ 在菜单中找到"设置形状格式"，点击
→ 在右侧面板中，点击"文本选项"（A图标，不是油漆桶）
→ 展开"文本框"选项
→ 找到"垂直对齐方式"下拉框
→ 选择"居中"

✅ 完成！此时文字应该在矩形中完美居中，白色加粗清晰可见。


■ 第四步：调整标注框位置（预计耗时：30秒）

【操作1：移动标注框到图片上方】
→ 用鼠标左键点击标注框（矩形），选中它
→ 按住鼠标左键不放，拖动标注框
→ 将标注框移动到第一张手机截图的正上方
→ 距离图片顶部留出一点空隙（约10-15像素，目测即可）

【操作2：精确居中对齐】
→ 按住Ctrl键，用鼠标依次点击"标注框"和"第一张图片"
   （此时两个对象都被选中，会同时显示选中状态）
→ 看PPT顶部工具栏，找到"形状格式"选项卡
→ 在"形状格式"选项卡中，找到"排列"组
→ 点击"对齐"按钮
→ 在下拉菜单中，点击"水平居中"

✅ 完成！标注框现在与图片完美居中对齐了。

■ 第五步：快速复制标注框到其他图片（预计耗时：2分钟）

【操作1：复制第一个标注框】
→ 用鼠标左键点击第一个标注框，确保它被选中
→ 按键盘上的 Ctrl+C（复制）
→ 按键盘上的 Ctrl+V（粘贴），会出现第二个标注框（和第一个重叠）
→ 再按一次 Ctrl+V，会出现第三个标注框

✅ 此时你应该有3个一模一样的标注框（可能叠在一起，不用担心）

【操作2：修改第二个标注框并移动】
→ 用鼠标点击其中一个标注框（任意一个）
→ 按住鼠标左键不放，拖动它到空白区域（先拉开，方便操作）
→ 双击这个标注框内部的文字
→ 用鼠标选中所有文字，或按 Ctrl+A 全选
→ 用键盘输入新文字："步骤2：智能决策"
→ 点击标注框外部，完成文字修改

→ 再次点击这个标注框，选中它
→ 按住鼠标左键不放，拖动到第二张图片的正上方
→ 松开鼠标

→ 精确居中：
  → 按住Ctrl键，依次点击"这个标注框"和"第二张图片"
  → 两个对象都被选中后，点击顶部"形状格式" → "对齐" → "水平居中"

✅ 完成！第二个标注框设置好了。

【操作3：修改第三个标注框并移动】
→ 重复上面的操作，将第三个标注框：
  → 文字改为："步骤3：无缝行动"
  → 移动到第三张图片正上方
  → 与第三张图片水平居中对齐

✅ 完成！三个标注框都设置好了。

■ 第六步：统一对齐三个标注框（关键！让PPT更专业）（预计耗时：1分钟）

【操作1：让三个标注框在同一水平线上】
→ 按住Shift键不放
→ 用鼠标依次点击三个标注框
   （点第一个 → 继续按住Shift → 点第二个 → 继续按住Shift → 点第三个）
→ 此时三个标注框都被选中了（周围都有选中标记）
→ 松开Shift键

→ 用鼠标右键点击其中任意一个被选中的标注框
→ 在弹出菜单中，找到"对齐"选项，鼠标移上去
→ 在子菜单中，点击"顶端对齐"

✅ 完成！三个标注框现在在同一水平线上了，看起来整齐专业。

【操作2（可选）：检查间距是否一致】
→ 目测检查三个标注框与各自图片的距离是否一致
→ 如果不一致，用鼠标拖动调整
→ 或者打开标尺辅助（菜单栏 → 视图 → 勾选"标尺"）

【配色建议】
====================================================================

根据你们PPT的主题色选择标注框颜色：

■ 科技蓝系（推荐）
- 深蓝色：RGB(30, 58, 138) / #1E3A8A
- 中蓝色：RGB(37, 99, 235) / #2563EB
- 文字：白色

■ 商务灰系
- 深灰色：RGB(51, 65, 85) / #334155
- 文字：白色

■ 活力橙系
- 橙色：RGB(249, 115, 22) / #F97316
- 文字：白色

■ 专业绿系
- 深绿色：RGB(22, 163, 74) / #16A34A
- 文字：白色

建议：与PPT主色调保持一致！

【常见问题与解决方案】（遇到问题必看！）
====================================================================

❌ 问题1：标注框里的文字不居中，靠上或靠下

✅ 解决方法（详细步骤）：
→ 用鼠标点击标注框，选中它（不是双击文字）
→ 右键点击标注框
→ 在菜单中点击"设置形状格式"
→ 在右侧面板中，点击"文本选项"图标（A字图标）
→ 点击"文本框"，展开选项
→ 找到"垂直对齐方式"下拉框
→ 选择"居中"
→ 完成！文字现在应该垂直居中了

---

❌ 问题2：阴影效果不明显或者看不到

✅ 解决方法（详细步骤）：
→ 右键点击标注框 → "设置形状格式"
→ 点击"效果"图标（五角星）
→ 展开"阴影"选项
→ 调整以下参数，让阴影更明显：
  * 模糊：增加到 12-15 磅（让阴影更柔和）
  * 大小：增加到 120%（让阴影更大）
  * 距离：增加到 6-8 磅（让阴影离得更远）
  * 透明度：调整到 40-50%（让阴影更深）
→ 完成！阴影应该明显了

---

❌ 问题3：三个标注框大小不一样

✅ 解决方法（详细步骤）：
→ 点击第一个标注框（做得最好的那个）
→ 看PPT顶部工具栏，找到"形状格式"选项卡
→ 在右侧"大小"组，记下"高度"和"宽度"的数值
   例如：高度 1.2厘米，宽度 4.5厘米

→ 点击第二个标注框
→ 在"形状格式"的"大小"组，手动输入相同的高度和宽度
→ 按回车确认

→ 对第三个标注框重复上述操作

→ 完成！三个标注框现在大小一致了

---

❌ 问题4：文字颜色是黑色，看不清（背景是深蓝色）

✅ 解决方法（详细步骤）：
→ 双击标注框的文字
→ 用鼠标拖动选中所有文字，或按 Ctrl+A 全选
→ 看顶部工具栏"开始"选项卡
→ 点击"字体颜色"按钮（A字下面有横线的那个）
→ 点击旁边的下拉箭头
→ 在颜色选择器中选择"白色"
→ 完成！文字现在变白色了

---

❌ 问题5：标注框的圆角太小，想要更圆润

✅ 解决方法（详细步骤）：
→ 用鼠标点击标注框，选中它
→ 仔细看标注框的四个角，会发现一个小小的"黄色圆点"
→ 用鼠标点击这个黄色圆点，按住不放
→ 向内拖动（往矩形中心方向），圆角会变大
→ 拖到合适的弧度后松开鼠标
→ 完成！标注框更圆润了

---

❌ 问题6：粘贴标注框后，新的标注框找不到了（可能叠在原位置）

✅ 解决方法（详细步骤）：
→ 按 Ctrl+V 粘贴后，新的标注框会和原标注框叠在一起
→ 不要点击其他地方，直接按住鼠标左键
→ 拖动鼠标到空白区域
→ 松开鼠标，你会看到新的标注框出现了
→ 完成！

---

❌ 问题7：想要渐变色背景效果，而不是纯色

✅ 解决方法（详细步骤）：
→ 右键点击标注框 → "设置形状格式"
→ 点击"填充"图标（油漆桶）
→ 选择"渐变填充"（点击前面的圆点）
→ 设置以下参数：
  * 类型：线性
  * 方向：选择"从左到右"
  * 光圈：点击左侧的光圈1，设置颜色为深蓝色（R30, G58, B138）
  * 光圈：点击右侧的光圈2，设置颜色为浅蓝色（R59, G130, B246）
→ 完成！标注框有渐变效果了

---

❌ 问题8：删除了标注框的边框后，又想加回来

✅ 解决方法（详细步骤）：
→ 右键点击标注框 → "设置形状格式"
→ 点击"线条"图标
→ 选择"实线"（点击前面的圆点）
→ 设置颜色（例如白色或其他颜色）
→ 设置宽度（例如 1-2 磅）
→ 完成！边框加回来了
