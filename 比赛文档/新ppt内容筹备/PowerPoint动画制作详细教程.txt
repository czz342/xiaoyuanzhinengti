====================================================================
PowerPoint动画制作详细教程 - 超详细版（保证学会）
====================================================================

【重要提醒】
- 本教程采用"手把手"教学，每一步都有详细说明
- 所有鼠标操作、菜单位置、参数设置都会明确标注
- 每个动画效果都会标注预计耗时
- 遇到问题请对照"常见问题"章节
- 建议先在空白PPT上练习一遍，再应用到实际页面

【教程说明】
本教程针对三个创新点的PPT动画制作，包含三种核心动画效果：
1. 文字聚焦动画（讲哪段放大，其他缩小变灰）
2. 步骤联动动画（步骤高亮 + 图片切换 + 标注出现）- 最复杂但效果最好
3. 数据对比动画（左右对比图的渐入效果）

【前置准备 - 必看！】

■ 软件要求：
- Microsoft PowerPoint 2016及以上版本
- 如果是WPS，部分操作可能略有不同，但原理相同

■ 打开"动画窗格"（重要工具，必须打开）：
→ 点击PPT顶部菜单栏的"动画"选项卡
→ 在"高级动画"组中，找到并点击"动画窗格"按钮
→ 此时PPT右侧会出现一个"动画窗格"面板
→ 这个面板会显示当前页面所有动画的列表，非常重要！

■ 基本概念：
- "选中对象"：用鼠标左键点击对象（文本框、图片等），周围会出现圆圈或方框
- "添加动画"：给对象加上进入、退出、强调等效果
- "调整顺序"：在动画窗格中拖动动画，改变播放顺序
- "触发方式"：
  * 单击时：点击鼠标才触发
  * 与上一动画同时：自动播放，和上一个动画同时发生
  * 与上一动画之后：自动播放，在上一个动画结束后立即发生

====================================================================
【动画效果一：文字聚焦动画】
实现效果：讲到哪块内容，哪块放大高亮，其他缩小变灰
====================================================================

■ 页面结构说明
假设你的PPT页面左侧有三个文本框：
- 文本框1：核心突破（这块内容）
- 文本框2：实现路径（这块内容）
- 文本框3：价值呈现（这块内容）

目标效果：当讲"核心突破"时，文本框1放大变色，文本框2、3缩小变灰

■ 详细制作步骤

【第一步：确保三个文本框格式一致】（预计耗时：1分钟）

→ 用鼠标点击"文本框1"，选中它
→ 看顶部工具栏"开始"选项卡
→ 确认字体大小：16号（或你喜欢的大小）
→ 确认字体颜色：黑色或深灰色

→ 对文本框2和文本框3做同样设置，确保三个文本框初始状态一致

✅ 完成！三个文本框现在格式统一。


【第二步：为文本框1添加"放大"动画】（预计耗时：2分钟）

【操作1：添加放大动画】
→ 用鼠标左键点击"文本框1"，确保它被选中
→ 看PPT顶部菜单栏，点击"动画"选项卡
→ 在"动画"选项卡中，找到"添加动画"按钮（不是"动画"按钮，是"添加动画"）
→ 点击"添加动画"右侧的下拉箭头
→ 在弹出的菜单中，找到"强调"分类
→ 在"强调"分类下，找到并点击"放大/缩小"

✅ 此时文本框1会自动播放一次放大动画预览。

【操作2：设置放大参数】
→ 看右侧的"动画窗格"（如果没有，回到前面"打开动画窗格"部分）
→ 在动画窗格中，会看到一个动画条目（可能显示"文本框1"或数字1）
→ 点击这个动画条目右侧的下拉箭头（小三角）
→ 在弹出菜单中，点击"效果选项"
→ 会弹出"放大/缩小"对话框

→ 在对话框中，找到"效果"选项卡
→ 看到"大小"设置，点击下拉框
→ 选择"自定义"
→ 在弹出的输入框中，输入：120%（表示放大到1.2倍）
→ 点击"确定"

→ 再次点击动画条目右侧的下拉箭头
→ 点击"计时"
→ 设置"持续时间"为0.5秒
→ 点击"确定"

✅ 完成！文本框1现在有了放大动画。


【第三步：为文本框1添加"变色"动画】（预计耗时：2分钟）

【操作1：添加颜色变化动画】
→ 再次点击"文本框1"，确保它被选中
→ 点击顶部"动画"选项卡 → "添加动画"下拉箭头
→ 在"强调"分类下，找到并点击"更改字体颜色"

【操作2：设置颜色和触发方式】
→ 在右侧动画窗格中，现在应该有两个动画了
→ 点击第二个动画（更改字体颜色）右侧的下拉箭头
→ 点击"效果选项"
→ 在"颜色"下拉框中，选择深蓝色或你的强调色
→ 点击"确定"

→ 再次点击第二个动画右侧的下拉箭头
→ 点击"计时"
→ 设置"持续时间"为0.5秒
→ 重点：设置"开始"为"与上一动画同时"（这样放大和变色同时发生）
→ 点击"确定"

✅ 完成！文本框1现在会同时放大和变色。

【第四步：为文本框2添加"缩小+变灰"动画】（预计耗时：3分钟）

【操作1：为文本框2添加缩小动画】
→ 用鼠标点击"文本框2"，选中它
→ 点击顶部"动画"选项卡 → "添加动画"下拉箭头
→ 在"强调"分类下，点击"放大/缩小"

→ 在右侧动画窗格中，找到刚添加的这个动画
→ 点击动画右侧的下拉箭头 → "效果选项"
→ 在"大小"设置中，选择"自定义"
→ 输入：85%（缩小到0.85倍）
→ 点击"确定"

→ 再次点击这个动画右侧的下拉箭头 → "计时"
→ 设置"持续时间"为0.5秒
→ 重点：设置"开始"为"与上一动画同时"（和文本框1的动画同时触发）
→ 点击"确定"

【操作2：为文本框2添加变灰动画】
→ 确保"文本框2"仍被选中
→ 点击"添加动画"下拉箭头 → "强调" → "更改字体颜色"

→ 在动画窗格中，找到刚添加的颜色动画
→ 点击右侧下拉箭头 → "效果选项"
→ 在"颜色"下拉框中，选择浅灰色（#CCCCCC或其他浅色）
→ 点击"确定"

→ 再次点击右侧下拉箭头 → "计时"
→ 设置"持续时间"为0.5秒
→ 设置"开始"为"与上一动画同时"
→ 点击"确定"

✅ 完成！文本框2现在会同时缩小和变灰。


【第五步：为文本框3添加"缩小+变灰"动画】（预计耗时：3分钟）

→ 重复第四步的所有操作，将对象换成"文本框3"：
  1. 添加"放大/缩小"动画 → 设置为85% → 0.5秒 → 与上一动画同时
  2. 添加"更改字体颜色"动画 → 浅灰色 → 0.5秒 → 与上一动画同时

✅ 完成！文本框3也会同时缩小和变灰。


【第六步：检查动画窗格并调整触发方式】（预计耗时：2分钟）

→ 看右侧的"动画窗格"
→ 现在应该有6个动画（文本框1两个，文本框2两个，文本框3两个）

→ 关键操作：确保这6个动画都设置为"单击时"触发
→ 逐个检查每个动画：
  * 点击动画右侧的下拉箭头
  * 查看"开始"是显示"单击时"还是"与上一动画同时"
  * 如果第一个动画（文本框1的放大）不是"单击时"，需要修改：
    - 点击下拉箭头 → "计时"
    - 将"开始"改为"单击时"
    - 点击"确定"
  * 其他5个动画应该都是"与上一动画同时"

最终状态应该是：
- 动画1（文本框1放大）：单击时
- 动画2（文本框1变色）：与上一动画同时
- 动画3（文本框2缩小）：与上一动画同时
- 动画4（文本框2变灰）：与上一动画同时
- 动画5（文本框3缩小）：与上一动画同时
- 动画6（文本框3变灰）：与上一动画同时

✅ 完成！现在播放时，点击一次鼠标，6个动画会同时触发。

【第七步：制作"讲文本框2"时的反转动画】（预计耗时：6分钟）

现在我们要做第二次点击的效果：文本框2放大变色，文本框1和3缩小变灰

【操作1：为文本框2添加放大+变色动画】
→ 点击"文本框2"，选中它
→ 重复第二步和第三步的操作：
  1. 添加"放大/缩小" → 120% → 0.5秒 → 单击时
  2. 添加"更改字体颜色" → 深蓝色 → 0.5秒 → 与上一动画同时

【操作2：为文本框1添加缩小+变灰动画】
→ 点击"文本框1"，选中它
→ 重复第四步的操作：
  1. 添加"放大/缩小" → 85% → 0.5秒 → 与上一动画同时
  2. 添加"更改字体颜色" → 浅灰色 → 0.5秒 → 与上一动画同时

【操作3：为文本框3添加缩小+变灰动画】
→ 点击"文本框3"，选中它
→ 重复第四步的操作：
  1. 添加"放大/缩小" → 85% → 0.5秒 → 与上一动画同时
  2. 添加"更改字体颜色" → 浅灰色 → 0.5秒 → 与上一动画同时

✅ 完成！现在动画窗格应该有12个动画了。


【第八步：制作"讲文本框3"时的动画】（预计耗时：6分钟）

→ 重复第七步的逻辑：
  * 文本框3：放大120% + 变色（深蓝） → 单击时
  * 文本框1：缩小85% + 变灰 → 与上一动画同时
  * 文本框2：缩小85% + 变灰 → 与上一动画同时

✅ 完成！现在动画窗格应该有18个动画。


【第九步：测试播放】（预计耗时：2分钟）

→ 按键盘上的 Shift+F5（从当前页开始播放）
→ 点击鼠标，应该看到：文本框1放大变色，文本框2、3缩小变灰
→ 再次点击鼠标，应该看到：文本框2放大变色，文本框1、3缩小变灰
→ 再次点击鼠标，应该看到：文本框3放大变色，文本框1、2缩小变灰
→ 按Esc退出播放

→ 如果效果不对，回到动画窗格检查每个动画的"开始"设置

✅ 文字聚焦动画完成！


■ 动画窗格最终状态
你的动画窗格应该有18个动画，分3组：

【第1组 - 点击1触发】
1. 文本框1放大（单击时）
2. 文本框1变色（与上一动画同时）
3. 文本框2缩小（与上一动画同时）
4. 文本框2变灰（与上一动画同时）
5. 文本框3缩小（与上一动画同时）

【第2组 - 点击2触发】
7. 文本框2放大（单击时）
8. 文本框2变色（与上一动画同时）
9. 文本框1缩小（与上一动画同时）
10. 文本框1变灰（与上一动画同时）
11. 文本框3缩小（与上一动画同时）
12. 文本框3变灰（与上一动画同时）

【第3组 - 点击3触发】
13. 文本框3放大（单击时）
14. 文本框3变色（与上一动画同时）
15. 文本框1缩小（与上一动画同时）
16. 文本框1变灰（与上一动画同时）
17. 文本框2缩小（与上一动画同时）
18. 文本框2变灰（与上一动画同时）


■ 快捷技巧（可选，不是必须）
如果你想节省时间，可以使用"复制粘贴动画"：
→ 选中已设置好动画的文本框1
→ 按 Ctrl+Shift+C（复制格式，包括动画）
→ 选中文本框2
→ 按 Ctrl+Shift+V（粘贴格式和动画）

注意：这个方法可能会复制全部动画，需要在动画窗格中手动删除不需要的

====================================================================
【动画效果二：步骤联动动画（最复杂但效果最好）】
实现效果：讲步骤1时，步骤1文字高亮+右侧只显示截图1+截图1标注出现
         讲步骤2时，步骤2文字高亮+截图1消失+截图2出现+截图2标注出现
====================================================================

■ 页面结构说明
假设你的PPT页面是这样布局的：
- 左侧：一个大的"实现路径"文本框，里面有三行文字：
  * 步骤1：智能感知
  * 步骤2：智能决策
  * 步骤3：无缝行动
- 右侧：3张手机截图图片（图片1、图片2、图片3），叠放在同一位置
- 每张图片上方有一个标注文本框（"步骤1：智能感知"等）

目标效果：
- 初始状态：只显示图片1，其他图片和所有标注都不可见
- 点击1：步骤1文字高亮，图片1的标注出现
- 点击2：步骤2文字高亮，图片1淡出，图片2淡入，图片2标注出现
- 点击3：步骤3文字高亮，图片2淡出，图片3淡入，图片3标注出现

■ 详细制作步骤

【第一步：设置初始状态 - 隐藏不需要的元素】（预计耗时：3分钟）

⚠️ 重要：我们要让图片2、图片3、以及所有标注在初始状态下不可见

【方法一：使用透明度（推荐，简单直接）】

→ 选中"图片2"
→ 右键点击 → "设置图片格式"
→ 在右侧面板中，点击"图片"图标（山的图标）
→ 展开"图片透明度"选项
→ 将透明度滑块拖到 100%（完全透明，不可见）

→ 对"图片3"重复上述操作

→ 选中"标注1"（图片1上方的标注文本框）
→ 右键 → "设置形状格式"
→ 点击"填充"图标 → 设置填充透明度为100%
→ 点击"线条"图标 → 设置线条透明度为100%
→ 点击"文本选项"图标 → 设置文本透明度为100%
（或者更简单：直接将整个标注框的对象透明度设为100%）

→ 对"标注2"和"标注3"重复上述操作

✅ 完成！现在页面上只能看到图片1，其他都隐藏了。

【方法二：使用动画隐藏（备选方案）】
如果方法一不行，可以给图片2、图片3、标注1、2、3都添加一个"退出 → 消失"动画，设置为"开始：与上一动画同时，触发：幻灯片开始时"。这里不详细展开，推荐用方法一。

【第二步：为"步骤1"文字添加高亮动画】（预计耗时：4分钟）

⚠️ 注意：如果你的"步骤1、2、3"是在同一个文本框内的三行文字，需要特殊处理：
- 方法1：将每行文字拆分成独立的文本框（推荐，方便控制）
- 方法2：使用"按段落"动画（但可能不够精确）

这里假设你已经将三行文字拆成了三个独立的文本框。

【操作1：为"步骤1"文字添加放大+变色动画】
→ 用鼠标点击包含"步骤1：智能感知"的文本框
→ 点击顶部"动画"选项卡 → "添加动画"下拉箭头
→ "强调" → "放大/缩小"
→ 在动画窗格中，设置：
  * 效果选项 → 大小：自定义 120%
  * 计时 → 持续时间：0.5秒
  * 计时 → 开始：单击时

→ 再次选中"步骤1"文本框
→ "添加动画" → "强调" → "更改字体颜色"
→ 设置：
  * 效果选项 → 颜色：深蓝色
  * 计时 → 持续时间：0.5秒
  * 计时 → 开始：与上一动画同时

【操作2：为"步骤2"和"步骤3"文字添加缩小+变灰动画】
→ 选中"步骤2"文本框
→ 添加"放大/缩小" → 85% → 0.5秒 → 与上一动画同时
→ 添加"更改字体颜色" → 浅灰色 → 0.5秒 → 与上一动画同时

→ 选中"步骤3"文本框
→ 添加"放大/缩小" → 85% → 0.5秒 → 与上一动画同时
→ 添加"更改字体颜色" → 浅灰色 → 0.5秒 → 与上一动画同时

✅ 完成！现在动画窗格应该有6个动画，都在同一次点击时触发。


【第三步：让"标注1"淡入出现】（预计耗时：2分钟）

→ 选中"标注1"（图片1上方的标注文本框，现在是透明不可见的）
→ 点击"添加动画" → "进入" → "淡入"
→ 在动画窗格中，设置：
  * 计时 → 持续时间：0.5秒
  * 计时 → 开始：与上一动画之后（让标注在文字动画结束后再出现）

✅ 完成！第一次点击的动画序列完成。

→ 测试：按Shift+F5播放当前页，点击鼠标，应该看到：
  * 步骤1文字放大变色
  * 步骤2、3文字缩小变灰
  * 图片1的标注淡入出现

【第四步：制作"步骤2"的动画序列】（预计耗时：8分钟）

现在制作第二次点击的效果：步骤2高亮，图片1消失，图片2出现

【操作1：为"步骤2"文字添加放大+变色动画】
→ 选中"步骤2"文本框
→ 添加"放大/缩小" → 120% → 0.5秒 → 单击时
→ 添加"更改字体颜色" → 深蓝色 → 0.5秒 → 与上一动画同时

【操作2：为"步骤1"和"步骤3"文字添加缩小+变灰动画】
→ 选中"步骤1"文本框
→ 添加"放大/缩小" → 85% → 0.5秒 → 与上一动画同时
→ 添加"更改字体颜色" → 浅灰色 → 0.5秒 → 与上一动画同时

→ 选中"步骤3"文本框
→ 添加"放大/缩小" → 85% → 0.5秒 → 与上一动画同时
→ 添加"更改字体颜色" → 浅灰色 → 0.5秒 → 与上一动画同时

【操作3：让"图片1"淡出消失】
→ 选中"图片1"
→ 点击"添加动画" → "退出" → "淡出"
→ 在动画窗格中，设置：
  * 计时 → 持续时间：0.3秒（快速淡出）
  * 计时 → 开始：与上一动画同时（和文字动画同时发生）

【操作4：让"图片2"淡入出现】
→ 选中"图片2"（现在是透明的）
→ 点击"添加动画" → "进入" → "淡入"
→ 设置：
  * 计时 → 持续时间：0.5秒
  * 计时 → 开始：与上一动画之后（在图片1淡出后立即淡入）

⚠️ 重要技巧：为了让图片切换更流畅，可以调整：
→ 在动画窗格中，找到"图片2淡入"这个动画

❌ 问题1：点击鼠标后，动画完全不触发，没有任何反应

✅ 解决方法（详细步骤）：
→ 打开右侧的"动画窗格"
→ 找到第一个动画（应该在最上面）
→ 点击这个动画右侧的下拉箭头 → "计时"
→ 检查"开始"选项：
  * 如果是"与上一动画同时"或"与上一动画之后"，改为"单击时"
→ 点击"确定"
→ 再次测试播放

原因：如果第一个动画不是"单击时"触发，就无法通过点击鼠标启动。

---

❌ 问题2：动画顺序乱了，先出现的后出现，后出现的先出现

✅ 解决方法（详细步骤）：
→ 打开右侧"动画窗格"
→ 仔细查看动画列表，从上到下就是播放顺序
→ 用鼠标左键点住某个动画，按住不放
→ 向上或向下拖动，调整到正确位置
→ 松开鼠标
→ 测试播放，确认顺序正确

技巧：动画窗格里的数字（1、2、3...）表示点击次数，相同数字的动画会同时触发。

---

❌ 问题3：图片切换时有明显的闪烁或跳跃

✅ 解决方法（详细步骤）：

【方法1：确保图片完全重叠】
→ 选中图片2
→ 看顶部工具栏，记下"位置X"和"位置Y"的数值
→ 选中图片3
→ 手动输入相同的"位置X"和"位置Y"
→ 三张图片现在完全重叠了

【方法2：使用"淡入/淡出"而不是"擦除"】
→ 在动画窗格中，检查图片的进入/退出动画
→ 如果用的是"擦除"、"飞入"等，改为"淡入/淡出"
→ 淡入淡出更柔和，不会闪烁

【方法3：调整图片2的淡入延迟】
→ 在动画窗格中，找到"图片2淡入"
→ 点击右侧下拉箭头 → "计时"
→ 将"延迟"设为0秒（无缝切换）或0.1秒（稍有停顿）
→ 测试哪个效果更好

---

❌ 问题4：文字高亮效果不明显，放大了但看不出区别

✅ 解决方法（详细步骤）：

【方法1：增加放大倍数】
→ 在动画窗格中，找到文字的"放大/缩小"动画
→ 点击右侧下拉箭头 → "效果选项"
→ 将"大小"改为130%或140%（更明显）
→ 点击"确定"

【方法2：增加颜色对比度】
→ 确保"更改字体颜色"动画的颜色设置正确：
  * 高亮时：深蓝色（#1E3A8A）或黑色（#000000）
  * 变灰时：浅灰色（#CCCCCC）或更浅
→ 对比越强，效果越明显

【方法3：同时使用加粗效果】
→ 选中需要高亮的文本框
→ 在"开始"选项卡中，点击"加粗"按钮（B）
→ 加粗的文字放大后更醒目

❌ 问题5：设置了透明度100%，但对象还是可见

✅ 解决方法（详细步骤）：
→ 选中对象
→ 右键 → "设置对象格式"（图片用"设置图片格式"，形状用"设置形状格式"）
→ 在右侧面板中，仔细查找"透明度"设置：
  * 对于图片：点击"图片"图标 → "图片透明度"
  * 对于形状：点击"填充"图标 → "透明度"
→ 拖动滑块到最右边（100%）
→ 如果还是可见，检查是否有边框：
  * 点击"线条"图标 → "透明度" → 100%
  * 或直接选择"无线条"

备选方案：直接删除对象，播放时再用"进入"动画让它出现。

❌ 问题6：动画播放速度太快或太慢

→ 点击"确定"
→ 测试播放

建议时长：
- 文字动画：0.5秒
- 图片淡入淡出：0.5秒
- 标注出现：0.3秒

❌ 问题11：文本框放大/缩小时出现错位，和原本的排版不对齐了！⭐⭐⭐

这是最常见的问题之一！原因是动画的"锚点"（缩放中心点）设置不对。

✅ 解决方法（详细步骤）：

【方法1：设置动画缩放的锚点位置（推荐，最有效）】

→ 在动画窗格中，找到文本框的"放大/缩小"动画
→ 点击右侧下拉箭头 → "效果选项"
→ 在弹出的对话框中，找到"缩放"或"方向"选项
→ 看到一个九宫格图标（表示缩放中心点）
→ 点击中间的格子（中心位置）

⚠️ 关键：确保选择"中心"作为缩放原点，这样文本会以自身中心为基准放大/缩小，不会位置偏移

→ 点击"确定"
→ 测试播放，文本应该在原地放大缩小了

---

【方法2：使用"组合"功能锁定位置】

如果方法1还有问题，可以用这个更强力的方法：

→ 选中需要一起动画的多个文本框
→ 按住Ctrl键，依次点击"文本框1"、"文本框2"、"文本框3"
→ 右键 → "组合" → "组合"
→ 现在三个文本框变成了一个整体

→ 对整体添加动画（这时不会错位）
→ 如果需要单独高亮某个文本框，可以：
  * 先取消组合：右键 → "组合" → "取消组合"
  * 分别添加动画
  * 但要确保每个文本框的位置完全固定

⚠️ 注意：组合后只能整体动画，不能单独控制。适合需要整体移动的场景。

---

【方法3：调整文本框的对齐方式】

→ 选中文本框
→ 右键 → "设置形状格式"
→ 在右侧面板中，点击"文本选项"图标（A图标）
→ 点击"文本框"展开选项
→ 找到"垂直对齐方式"：选择"居中"
→ 找到"水平对齐方式"：也选择"居中"

→ 确保文本在文本框内是居中对齐的
→ 再设置动画的锚点为"中心"（参考方法1）
→ 测试播放

---

【方法4：固定文本框大小，避免自动调整】

→ 选中文本框
→ 右键 → "设置形状格式"
→ 在"文本框"选项中，找到"自动调整"设置
→ 取消勾选"根据文本调整形状大小"
→ 选择"不自动调整"

→ 手动设置文本框的宽度和高度（例如：宽8厘米，高2厘米）
→ 确保文本在框内完全显示，且框的大小固定
→ 这样放大缩小时，文本框不会因为内容改变而移动

---

【方法5：使用"强调 - 更改字号"代替"放大/缩小"（终极方案）】

如果以上方法都解决不了，可以换一个动画效果：

→ 删除原来的"放大/缩小"动画
→ 选中文本框
→ 添加动画：强调 → "更改字号"
→ 在"效果选项"中设置：
  * 字号：相对于当前：150%（相当于放大1.5倍）
→ 持续时间：0.5秒
→ 开始：单击时

⚠️ 这个方法直接改变字体大小，而不是缩放整个文本框，通常不会错位

---

【方法6：检查文本框是否设置了边距】

→ 选中文本框
→ 右键 → "设置形状格式"
→ 在"文本框"选项中，找到"内部边距"
→ 将左、右、上、下边距都设置为 0 厘米
→ 这样文本紧贴文本框边缘，减少错位可能

---

【最佳实践建议】

为了避免文本错位问题，建议按以下步骤设置：

1️⃣ **统一文本框大小**：
   - 三个文本框设置为相同的宽度和高度
   - 例如：宽度8厘米，高度1.5厘米

2️⃣ **统一文本对齐**：
   - 所有文本都设置为"居中对齐"（水平+垂直）

3️⃣ **固定文本框位置**：
   - 使用"对齐"工具精确定位
   - 菜单栏 → 开始 → 排列 → 对齐 → 垂直分布

4️⃣ **设置动画锚点为中心**：
   - 每个"放大/缩小"动画都设置锚点为"中心"

5️⃣ **测试并微调**：
   - 播放测试，如果还有轻微错位
   - 在动画窗格中调整"效果选项"的缩放百分比
   - 例如从120%改为115%或125%

---

💡 **快速诊断**：

如果文本框：
- 向上或向下偏移 → 锚点设置为"顶部"或"底部"了，改为"中心"
- 向左或向右偏移 → 锚点设置为"左侧"或"右侧"了，改为"中心"
- 到处乱跑 → 文本框可能设置了"自动调整大小"，改为固定大小

【快速上手练习】
====================================================================

建议先在空白PPT上练习：
1. 创建3个文本框
2. 练习"聚焦动画"（5分钟）
3. 创建2张图片
4. 练习"图片切换动画"（10分钟）
5. 创建左右对比结构
6. 练习"对比动画"（10分钟）

熟练后，应用到实际PPT页面，每页大约15-20分钟可以完成全部动画。

====================================================================
【最终检查清单】
====================================================================

☑ 每个动画的触发方式正确（单击 vs 与上一动画同时/之后）
☑ 动画时长合理（不要太快或太慢）
☑ 文字高亮效果明显（颜色、大小对比清晰）
☑ 图片切换流畅（无闪烁、无跳跃）
☑ 标注出现时机正确（图片出现后立即或同时出现）
☑ 数字强调效果突出（放大+脉冲/颜色变化）
☑ 完整播放测试3遍，确保无问题
