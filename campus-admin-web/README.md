# 校园生活管理系统 - PC管理端

## 项目简介

这是校园生活管理系统的PC端管理后台，为管理员提供全面的校园服务管理功能，包括数据可视化、用户管理、各模块管理等。

## 技术栈

- **前端框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI组件库**: Element Plus
- **图表库**: ECharts
- **状态管理**: Pinia
- **路由管理**: Vue Router 4
- **HTTP客户端**: Axios

## 功能模块

### 🏠 首页数据看板
- 今日总览：活跃用户数、订单总数、预约总数、活动参与数
- 实时数据流：食堂订单实时滚动、自习室占用率
- 异常告警：设备故障、库存不足、超时未处理订单
- 趋势图表：7天/30天各模块数据对比

### 📊 各模块管理
1. **用户管理** - 用户列表、状态管理、数据可视化
2. **课程管理** - 课程CRUD、课表管理、选课统计
3. **教室管理** - 教室台账、使用率热力图、预约管理
4. **自习室管理** - 座位管理、实时占用率、预约分析
5. **图书馆管理** - 书目管理、借阅统计、逾期分析
6. **食堂管理** - 菜品管理、实时订单、人流热力图
7. **快递驿站** - 驿站管理、包裹流转、容量分析
8. **共享设备** - 设备管理、使用率统计、收益分析
9. **医务室** - 科室管理、就诊统计、医生工作量
10. **心理中心** - 咨询师管理、咨询统计、满意度分析
11. **校园圈子** - 帖子管理、举报处理、互动分析
12. **跑腿服务** - 订单管理、服务分析、信誉统计
13. **社团管理** - 社团入驻、活动管理、协作网络

## 数据说明

### 真实数据 vs 假数据
- **真实数据**: 增删改查操作使用后端接口
- **假数据**: 可视化图表使用前端生成的模拟数据
- **数据切换**: 预留接口，后续可轻松切换到真实数据

### 假数据特点
- 数据范围和趋势符合校园场景
- 支持不同时段、不同模块的数据变化
- 可配置数据范围、刷新频率
- 避免数据过于规律，增加真实感
