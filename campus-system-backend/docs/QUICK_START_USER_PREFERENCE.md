# 🚀 用户偏好功能 - 5分钟快速上手

## ⚡ 快速开始（3步）

### 步骤1：创建数据库表 (30秒)

```bash
cd campus-system-backend
node scripts/create-user-preference-table.js
```

看到 `✅ 数据库表创建完成` 即成功！

### 步骤2：启动后端服务

```bash
npm start
```

服务运行在 `http://localhost:3000`

### 步骤3：测试功能 (可选)

```bash
node test-user-preference.js
```

## 🎨 比赛亮点说明

### 亮点1：智能记忆，无感学习
- ❌ 传统方式：需要用户手动填写偏好表单
- ✅ 我们的方案：自动从对话中学习，无需用户操作

### 亮点2：本地轻分析，快速响应
- ❌ 复杂方案：需要调用外部NLP服务，延迟高
- ✅ 我们的方案：基于关键词匹配，本地处理，毫秒级响应

### 亮点3：持续优化，越用越智能
- 频率加权：提到越多的偏好优先级越高

- 自动淘汰：长期未提及的偏好逐渐降权

### 亮点4：多模块复用
- 自习室预约
- 图书馆借书
- 食堂点餐

## 🆘 常见问题

### Q1: 没有提取到关键词？
**A:** 检查消息是否包含预设关键词。可以运行：
```bash
node test-user-preference.js
```
查看当前支持的关键词列表。

### Q2: 偏好没有注入到对话中？
**A:** 确认：
1. 消息包含自习室相关关键词（自习室、座位、预约等）
2. 用户已有历史对话记录
3. 查看浏览器控制台是否有相关日志

### Q3: 如何清空测试数据？
**A:** 
```sql
DELETE FROM user_preferences WHERE student_id = '测试学号';
DELETE FROM ai_conversation_history WHERE student_id = '测试学号';
```
