# 智能推荐功能说明

## 概述

智能推荐功能为校园生活管理系统提供个性化的服务推荐，包括即将上课提醒、食堂人流量监控和自习室空位查询。

## 功能模块

### 1. 即将上课提醒

**API端点**: `GET /api/smart-recommendation/upcoming-class`

**功能描述**: 
- 根据当前用户和当前时间，智能判断下一节课信息
- 计算距离上课的剩余时间
- 提供课程名称、地点、教师等详细信息

**请求头**: 
```
Authorization: Bearer <token>
```

**响应示例**:
```json
{
  "success": true,
  "message": "ok",
  "data": {
    "hasUpcomingClass": true,
    "nextClass": {
      "name": "高等数学（II）",
      "location": "理科楼 A306",
      "teacher": "张教授",
      "startTime": "08:00:00",
      "endTime": "09:40:00"
    },
    "timeUntilClass": 45,
    "currentTime": "07:15:00"
  }
}
```

### 2. 食堂人流量监控

**API端点**: `GET /api/smart-recommendation/canteen-traffic`

**功能描述**:
- 实时监控各食堂的人流量状态
- 根据时间段智能判断人流量等级
- 提供可视化的人流量数据

**响应示例**:
```json
{
  "success": true,
  "message": "ok",
  "data": {
    "canteens": [
      {
        "id": 1,
        "name": "第一食堂",
        "location": "学生生活区A栋",
        "trafficLevel": "crowded",
        "trafficCount": 650,
        "status": "open",
        "openTime": "06:00:00",
        "closeTime": "22:00:00"
      }
    ],
    "updateTime": "12:30"
  }
}
```

**人流量等级**:
- `idle`: 空闲 (绿色)
- `moderate`: 适中 (浅黄色)  
- `busy`: 繁忙 (橙色)
- `crowded`: 拥挤 (红色)

### 3. 自习室空位查询

**API端点**: `GET /api/smart-recommendation/study-room-availability`

**功能描述**:
- 实时查询各自习室的座位占用情况
- 计算空位数量和占用率
- 提供座位预约状态和建议

**响应示例**:
```json
{
  "success": true,
  "message": "ok",
  "data": {
    "studyRooms": [
      {
        "id": 1,
        "name": "中央图书馆 3F",
        "location": "图书馆3楼",
        "totalSeats": 105,
        "availableSeats": 42,
        "bookedSeats": 63,
        "occupancyRate": 60,
        "statusText": "空位较多",
        "statusClass": "status-good",
        "statusColor": "#00B578",
        "openTime": "08:00:00",
        "closeTime": "22:00:00"
      }
    ],
    "updateTime": "12:30"
  }
}
```

**状态分类**:
- `status-good`: 空位较多 (绿色)
- `status-moderate`: 空位适中 (绿色)
- `status-warning`: 即将满座 (橙色)
- `status-full`: 已满座 (红色)

## 数据初始化

### 运行初始化脚本

```bash
# 初始化智能推荐相关数据
npm run init-smart-recommendation
```

### 初始化内容包括

1. **自习室数据**: 3个自习室，包含座位信息
2. **食堂数据**: 3个食堂的基本信息
3. **课程数据**: 示例课程和课程安排
4. **座位数据**: 每个自习室的详细座位信息

## 前端集成

### 服务大厅页面

前端页面 `pages/services/index.vue` 已集成这三个功能卡片：

1. **即将上课卡片**: 显示下一节课信息和倒计时
2. **食堂人流量卡片**: 显示人流量柱状图和状态
3. **自习室空位卡片**: 显示各自习室空位情况

### 数据获取流程

1. 页面加载时调用相应API获取数据
2. 根据时间判断是否显示相应卡片
3. 实时更新数据和时间戳

## 技术特点

### 后端特性

- **智能时间判断**: 根据当前时间自动判断用餐时间和课程时间
- **实时数据计算**: 动态计算座位占用率和人流量状态
- **错误处理**: 完善的错误处理和日志记录
- **权限控制**: 即将上课API需要用户认证

### 前端特性

- **条件渲染**: 根据数据和时间智能显示卡片
- **实时更新**: 自动刷新数据和时间戳
- **响应式设计**: 适配不同屏幕尺寸
- **用户体验**: 平滑的动画和交互效果

## 配置说明

### 时间配置

- **用餐时间**: 早餐(6-9点)、午餐(11-14点)、晚餐(17-20点)
- **自习室开放时间**: 根据各自习室实际开放时间配置
- **课程时间**: 支持灵活的课程时间安排

### 状态阈值

- **人流量阈值**: 根据实际需求可调整
- **座位占用率**: 30%、70%、90% 为状态分界点
- **更新频率**: 页面显示时自动更新
