### 6. **实体关系图**
```
User (用户)
├── 发布订单 (1:N) → ErrandOrder
├── 接单 (1:N) → ErrandOrder  
├── 评价 (1:N) → OrderReview
└── 包含信誉信息 (直接字段)

ErrandOrder (订单)
├── 状态变更 (1:N) → OrderStatusLog
├── 评价 (1:2) → OrderReview (发布者评价接单者，接单者评价发布者)
├── 发布者 (N:1) → User
└── 接单者 (N:1) → User
```
